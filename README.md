# Isaac Obert — personal website

This is a dependency-free static website designed for free GitHub Pages hosting.

## Preview locally

From this folder, run a local server such as:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Publish on GitHub Pages

1. Create a new public repository on GitHub, ideally named `isaac-obert-website`.
2. Upload `index.html`, `styles.css`, `README.md`, and `Obert CV.pdf`.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will provide the public website URL.

Before publishing, review the contact details and replace the CV file if needed.
